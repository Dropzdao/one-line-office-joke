"One-Line Office Joke: 24-Hour Sprint". The program writes the joke to
`/output/entry.txt` — one line, 131 characters, no setup, no explanation.

> Our shared drive has folders named final, final_v2, and final_FINAL_use_this_one, and nobody in the office knows which one is real.

## Run it
